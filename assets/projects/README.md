# Project assets

Place your files here so the [Recent Projects](../../README.md#-recent-projects) section renders correctly.

### Mirra (`mirra/`)

| File | Purpose |
|------|---------|
| `screen-1.gif` | First animated screen (e.g. journaling UI) |
| `screen-2.gif` | Second animated screen (e.g. insights / coach) |
| `screen-3.gif` | Third animated screen (e.g. goals / actions) |

**Tips:** Use [Kap](https://getkap.co/), [LICEcap](https://www.cockos.com/licecap/), or [Giphy Capture](https://giphy.com/apps/giphycapture) to record short clips and export as GIF. Keep them short (3–8 sec) and under ~2MB for fast loading.
